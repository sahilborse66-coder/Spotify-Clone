# 🎵 Spotify Clone

A Spotify-inspired music player web application built using HTML, CSS and JavaScript.

## 🚀 Features

- Spotify-inspired dark UI
- Music, Podcasts and All category buttons
- Active category button switching
- Previous, Play/Pause and Next controls
- Music album cards
- Hover animations
- Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- SVG
